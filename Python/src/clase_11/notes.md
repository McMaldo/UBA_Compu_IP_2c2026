# Secuencias en Python

### Lista

```Python
diccionario: [int] = [1, 2, 3]
```

### Set


```Python
s : set [int] = {6, 7}
```

### Diccionario

```Python
diccionario: dict[str, str] = {"key": "value", "key1": "value1"}
```

### Tuplas / N-uplas


```Python
tupla: tuple[int, str] = (1, "2")

n_tupla: tuple[int, ...] = (1, 2, 3, 4)
```

# Parametros (Además del Tipo)

- **in** --> param que no se modifica y se lee su valor

- **inout** --> param que se modifica y se lee su valor

- **out** --> param que se modifica al terminar la función (debe inicializarse porque no importan los valores de entrada)
